# testing_docs

A small practice repo for learning how documentation works in Git/GitHub:
how files are organised, and how `README.md` links them together.

## Contents

- [Project layout](#project-layout)

## Project layout

```
testing_docs/
├── README.md          ← you are here (the entry point GitHub shows first)
├── notes              ← scratch notes
└── docs/
    ├── source/        ← input docs (what the data/tables are)
    │   └── tables
    └── outputs/       ← generated / result docs
```
